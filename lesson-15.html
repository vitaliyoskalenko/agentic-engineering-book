01

Що саме ви обираєтеП'ять рішень під однією назвою

Назва продукту ховає п'ять незалежних рішень. Два інструменти можуть працювати з однією моделлю і поводитися по-різному (урок 2.3), а один інструмент — бути дешевим у підписці й дорогим на виході з нього.

Продуктове мислення

Питання «хто кращий» не має відповіді без задачі. Робочі питання: де команда вже живе (термінал, IDE, GitHub), хто платить і як (підписка на людину чи токени на рахунок), що мусить контролювати адмін і скільки коштуватиме піти, коли вендор змінить тарифи. За останні пів року троє з п'ятьох вендорів змінили модель доступу — дивіться далі.

AGENTS.md як крос-інструментний стандарт

Формат випустила OpenAI в серпні 2025; 09.12.2025 він став одним із трьох стартових проєктів Agentic AI Foundation під Linux Foundation, поруч із MCP. Сайт agents.md заявляє понад 60 тисяч проєктів і правило вкладених файлів: діє найближчий до редагованого файла AGENTS.md, а явний запит у чаті переважає все. Хмарний агент переносить межу безпеки з вашого ноутбука в процес рев'ю: найсильніший контроль у таблиці — не VM, а правила Copilot «лише своя гілка» і «CI стартує після людини». Якщо обираєте хмарного агента іншого вендора, відтворіть ці два правила самі: захист гілок і ручний запуск workflow для PR від бота.

Продуктове мислення

Дві моделі оплати по-різному розподіляють ризик. Підписка на людину — передбачуваний бюджет, але ліміт закінчується посеред задачі. Оплата за токени — платите за роботу, але один агент у циклі спалює місячний бюджет за ніч, тому потрібні ліміти з уроку 2.2. Copilot за рік перейшов із запитів на токени, Cursor — на пули з окремою платою за чужі моделі: закладайте в рішення, що модель оплати зміниться.

06

БенчмаркиЩо з них можна чесно взяти

Незалежних рейтингів «інструментів» немає. Є бенчмарки, де оцінюють пару harness + модель з конкретним рівнем міркувань.

Terminal-Bench 4.0 (реліз 26.08.2026): довгі задачі в терміналі з різних доменів — бази даних, ML-чекпоінти, RTL-дизайни, формальні доведення, код на Python, C і CUDA, середовища з кількома контейнерами й GPU. У версії 4.0 вісім задач прибрали і 19 виправили, лишилося 66; одна спроба лідера триває в середньому 80 хвилин. Таблиця має окремі колонки для агента, моделі, effort, токенів і вартості прогону.

  • Ціна за бал різниться в рази: між другою і третьою позицією 3,6 п. п. при вартості прогону $7,3 тис. проти $0,6 тис. Для CI з сотнями запусків це важливіше за перше місце.
  • Effort — така сама змінна, як модель: та сама пара Claude Code + Fable 5.1 дає 43,3% на low і 57,9% на max.
  • Похибка ±3 п. п. робить місця 3–8 статистично нерозрізненними.

SWE-bench Verified розділяє дві таблиці: повна порівнює довільні системи, а Bash Only проганяє всі моделі в одному мінімальному harness (mini-SWE-agent) — «scores compare models rather than harnesses». Останні записи датовані лютим 2026, тож для свіжих моделей це вже історія.

Як читати будь-який рейтинг

Перевірте п'ять речей: дата рядка, хто подав (вендор чи незалежні), harness і effort, похибка, вартість. Якщо чогось із цього немає — це маркетинг, а не вимір. Свій вимір — 10–20 задач з вашого репозиторію з автоматичною перевіркою (модуль 12).

# ADR 0001 — Coding agents
Status: accepted · 14.10.2026

## Context
Solo author, terminal-first, Python;
1 occasional contributor, tool unknown.
Runtime uses Claude Code (agent_sdk.py);
agent_api.py is the exit path.
Budget: 1 subscription; no SSO needs.

## Options
A Claude Code · B Claude Code + Codex CLI
C Cursor · D Copilot cloud agent

## Decision
B. Primary: Claude Code — same harness
as the product runtime; hooks, skills.
Secondary: Codex CLI — cross-model review
of risky diffs; Apache-2.0, AGENTS.md.
AGENTS.md = single source of rules;
CLAUDE.md = "@AGENTS.md" + Claude notes.

## Consequences
+ Contributor's tool reads AGENTS.md.
+ Checks live in `make check`; hooks
  only call it, so no hook lock-in.
- Two vendors to track: revisit on a
  pricing or AGENTS.md support change.

Квіз11 питань

11 питань
1. У репозиторії є AGENTS.md з правилами команди і CLAUDE.md з двома рядками про стиль комітів. Розробник у Claude Code скаржиться, що агент не знає команди тестів з AGENTS.md. Чому?
Так. З 2.1.277 Claude Code читає AGENTS.md лише за відсутності CLAUDE.md; імпорт @AGENTS.md або режим claude-md-and-agents-md вмикають обидва.
Ліміт 32 KiB — це Codex, а «діє найближчий файл» — правило agents.md і Copilot. Claude Code читає AGENTS.md, але типово лише тоді, коли поруч немає CLAUDE.md.
2. Команда живе на одному AGENTS.md. Розробниця створює собі CLAUDE.local.md з особистими нотатками. Що зміниться для неї?
Так. CLAUDE.local.md рахується як CLAUDE.md, і типовий режим вимикає AGENTS.md. Рішення — claude-md-and-agents-md.
Документація прямо попереджає: CLAUDE.local.md входить у перевірку «чи є CLAUDE.md», тож AGENTS.md більше не завантажується — ні як доповнення, ні як другий файл.
3. Банк хоче хмарного агента, який бере issue і повертає PR, але жоден код від бота не має запускатися в CI без людини. Що найближче до цього з коробки?
Так. VM ізолює виконання задачі, але не ваш CI; правило ручного запуску workflow — саме те, що потрібно.
Ізоляція VM захищає машину агента, а не ваш pipeline: PR від бота однаково запускає workflow. Copilot cloud agent не запускає workflow до схвалення людиною і не зливає PR сам.
4. Terminal-Bench 4.0: Claude Code + Opus 5.5 — 64,8% за $4,7 тис., Codex + GPT-6.1 Sol — 58,2% за $0,6 тис. (обидва ±3 п. п.). Ви плануєте сотні прогонів агента в CI на місяць. Який висновок коректний?
Так. Бенчмарк оцінює пари harness + модель + effort, а для масового CI вартість у 7 разів — аргумент такої самої ваги, як 6,6 п. п.
Рейтинг не порівнює «інструменти» окремо від моделі й effort і не знає вашого розподілу задач. Перевага в балах реальна, але різниця в ціні — у рази; перевірте обидві пари на своїх задачах.
5. Колега каже: «Cursor і Copilot немає в Terminal-Bench 4.0, отже вони слабші». Що відповісти?
Так. Рядки з'являються, коли хтось подає прогін. Висновків про тих, кого немає, бенчмарк не дає.
Таблиця містить лише подані прогони, тож про відсутніх вона мовчить. До того ж обидва інструменти мають CLI (agent, copilot).
6. Стартап на Cursor Plus хоче підключити свій ключ Anthropic, щоб заощадити і «залишити Zero Data Retention». Що не так?
Так. До того ж на старших планах ключ працює лише для chat-моделей, Tab лишається на моделях Cursor.
Документація Cursor прямо каже, що його Zero Data Retention на власні ключі не поширюється, а на Plus їх і не підключити. І навпаки: ключ працює для chat-моделей, а Tab лишається на моделях Cursor.
7. Вимога: лише відкритий код harness і жодної хмари вендора — модель локальна. Що обрати з п'ятірки?
Так. Відкритий CLI і офіційна підтримка локальних провайдерів.
Gemini CLI відкритий, але працює лише з моделями Gemini через платний ключ або ліцензію; --sandbox обмежує доступ до файлів, а не те, куди йдуть запити. Claude Code пропрієтарний, а маршрутизацію на не-Claude моделі документація не підтримує.
8. У прогоні уроку: 179 836 токенів прочитано з кешу, 1 689 згенеровано, $0,0049. Що з цього найкорисніше для порівняння інструментів?
Так. Робота — менше 1% токенів; решта — системний промпт і визначення інструментів, які кожен harness має свої. Порівнюйте на своїх задачах.
Понад 99% токенів займає контекст самого агента, тож прайс за вихід мало що каже. А кеш — не викривлення, а нормальний режим: без нього той самий контекст коштував би в рази дорожче.
9. У команди 12 hooks Claude Code з логікою перевірок усередині JSON-команд. Додають Codex як другий інструмент. Що зробити спершу?
Так. Hooks мають різні події й формати; спільний скрипт робить їх тонкими і переносними.
Дублювати логіку у двох форматах — подвоїти lock-in. Правило в AGENTS.md — інструкція для моделі, а не перевірка, яку запускає harness. Codex має hooks, і вони типово увімкнені; спільний скрипт пишеться один раз.
10. Бюджет на Copilot для команди склали за статтею минулого року в «premium requests». Що перевірити?
Так. Модель оплати змінилася з запитів на токени, і ціна взаємодії тепер залежить від моделі й обсягу.
Перейменування агента (01.04.2026) — окрема зміна, а request-based billing замінено оплатою за токени з 01.06.2026. CLI і Copilot app є в усіх планах; лише cloud agent — у платних.
11. Соло-розробник у терміналі на підписці Claude хоче другий інструмент для крос-рев'ю ризикових diff. Який вибір найкраще обґрунтований?
Так. Різні родини моделей помиляються по-різному, а спільний AGENTS.md не вимагає дублювати правила.
Модель тієї самої родини ловить менше нових помилок. Безкоштовний доступ Gemini CLI через Google-акаунт припинено 18.06.2026, а AGENTS.md він типово не читає.

Домашнє завданняДві задачі з AI-перевіркою

1. ADR вибору інструментів для вашої команди

Опишіть свою ситуацію, порівняйте щонайменше три інструменти за п'ятьма шарами з фактами, датою і посиланнями, оберіть основний і запасний і запишіть ADR із планом зменшення ціни переходу.

2. Міні-бенчмарк на власних задачах

Проженіть три задачі з автоматичною перевіркою через дві конфігурації (два інструменти або один з різними моделями чи effort) і порівняйте успіх, ходи, час і ціну за звітами інструментів.
